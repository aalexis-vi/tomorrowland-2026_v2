PROYECTO WEB: DAVID GUETTA
==========================

Estructura:
- index.html
- css/styles.css

Cómo abrir:
1. Descomprime el archivo ZIP.
2. Abre index.html en Chrome, Edge o Firefox.
3. Necesitas conexión a internet para cargar Bootstrap, Google Fonts y abrir enlaces externos.

Bootstrap incluido:
- Navbar responsive con menú hamburguesa.
- Grid con container, row, col-*, row-cols-* y breakpoints.
- Botones y utilidades de espaciado.
- Bootstrap 5.3.3 por CDN.

Personalización:
- Los estilos principales están en css/styles.css.
- La portada usa una composición gráfica CSS. Puedes reemplazar el bloque visual por una fotografía autorizada del artista si lo necesitas.
- El contenido es una página informativa no oficial. Verifica fechas, lanzamientos y próximos eventos en canales oficiales antes de publicar.
